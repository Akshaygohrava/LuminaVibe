LuminaVibe - SQL Database Query Q&A (Interview Prep)
===================================================
Below is a list of 35 database query questions and answers matching the schema of LuminaVibe. These queries target a specific user (e.g., User ID = 11) and illustrate how the tables (users, follows, posts, comments, likes, messages, and settings) interact.

---

Q1: How do you find the full name and username of User 11?
Answer:
SELECT full_name, username FROM users WHERE user_id = 11;

---

Q2: How do you retrieve all followers of User 11 (their names and usernames) whose follow request is accepted?
Answer:
SELECT u.user_id, u.full_name, u.username 
FROM follows f
JOIN users u ON f.follower_id = u.user_id
WHERE f.following_id = 11 AND f.status = 'ACCEPTED';

---

Q3: How do you retrieve all users that User 11 is currently following (their names and usernames)?
Answer:
SELECT u.user_id, u.full_name, u.username 
FROM follows f
JOIN users u ON f.following_id = u.user_id
WHERE f.follower_id = 11 AND f.status = 'ACCEPTED';

Q10: How do you find all mutual followers of User 11 (users who follow User 11 AND whom User 11 follows back)?
Answer:
SELECT u.user_id, u.username, u.full_name
FROM users u
WHERE u.user_id IN (
    SELECT f1.follower_id FROM follows f1 WHERE f1.following_id = 11 AND f1.status = 'ACCEPTED'
) AND u.user_id IN (
    SELECT f2.following_id FROM follows f2 WHERE f2.follower_id = 11 AND f2.status = 'ACCEPTED'
);

Q11: How do you find the total number of likes received across all of User 11's posts?
Answer:
SELECT COUNT(*) AS total_likes_received 
FROM likes l
JOIN posts p ON l.target_id = p.post_id
WHERE p.user_id = 11 AND l.target_type = 'post';

Q12: How do you find the top 3 most liked posts of User 11?
Answer:
SELECT p.post_id, p.content, COUNT(l.like_id) AS like_count
FROM posts p
LEFT JOIN likes l ON p.post_id = l.target_id AND l.target_type = 'post'
WHERE p.user_id = 11
GROUP BY p.post_id
ORDER BY like_count DESC
LIMIT 3;

FROM messages

Q21: How do you find the last message exchanged between User 11 and each of their active chat contacts?
Answer:
SELECT m1.*
FROM messages m1
WHERE m1.message_id IN (
    SELECT MAX(m2.message_id)
    FROM messages m2
    WHERE m2.sender_id = 11 OR m2.receiver_id = 11
    GROUP BY CASE 
        WHEN m2.sender_id = 11 THEN m2.receiver_id 
        ELSE m2.sender_id 
    END
)
ORDER BY m1.created_at DESC;

Q28: How do you calculate the engagement rate of User 11's posts (defined as (Likes + Comments) / Total Posts)?
Answer:
SELECT 
    p_count.total_posts,
    (COALESCE(l_count.total_likes, 0) + COALESCE(c_count.total_comments, 0)) AS total_engagement,
    CASE 
        WHEN p_count.total_posts = 0 THEN 0.0
        ELSE ((COALESCE(l_count.total_likes, 0) + COALESCE(c_count.total_comments, 0)) / p_count.total_posts) * 100.0
    END AS engagement_rate_percentage
FROM (SELECT COUNT(*) AS total_posts FROM posts WHERE user_id = 11) p_count
CROSS JOIN (
    SELECT COUNT(*) AS total_likes 
    FROM likes l
    JOIN posts p ON l.target_id = p.post_id AND l.target_type = 'post'
    WHERE p.user_id = 11
) l_count
CROSS JOIN (
    SELECT COUNT(*) AS total_comments 
    FROM comments c
    JOIN posts p ON c.post_id = p.post_id
    WHERE p.user_id = 11
) c_count;

Q29: How do you find users who have liked every post made by User 11?
Answer:
SELECT u.user_id, u.username
FROM users u
WHERE NOT EXISTS (
    SELECT p.post_id FROM posts p WHERE p.user_id = 11
    EXCEPT
    SELECT l.user_id FROM likes l 
    JOIN posts p2 ON l.target_id = p2.post_id AND l.target_type = 'post'
    WHERE p2.user_id = 11 AND l.user_id = u.user_id
);
